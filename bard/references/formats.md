# Formats and adaptation

Load before drafting when the main deliverable is spoken, slides, a length ladder, or a specific written format. Load again at step 7 for any extra formats, and adapt those from the finished, critiqued draft rather than from the outline, so every version keeps the same verified material.

## Length ladder

Write the logline first; it forces the core to be clear. Then draft and critique the longest rung, derive the shorter ones from it, and deliver all of them shortest to longest.

| Rung | Length | Shape |
|---|---|---|
| Logline | 1 sentence | Protagonist + want + obstacle + stakes |
| ABT | ~25–50 words | And, But, Therefore (see `references/structures.md`) |
| Short | ~100–150 words | ABT form, opened with a hook |
| Standard | ~300–600 words | The primary structure with one scene |
| Full | as briefed | The primary structure with all scenes |

Each rung must stand alone; don't make the short version a teaser for the long one unless the user asked for a teaser.

## Talk script

- **Timing:** spoken pace is roughly 130–150 words per minute. A 5-minute talk is about 700 words. Scripts that run long almost always run over time on stage.
- **Spoken prose:** shorter sentences, simpler syntax, no parentheticals, no nested clauses. Numbers rounded for the ear ("almost two hours", not "117 minutes") unless the exact number is the point.
- **Signposting and repetition** are allowed in speech, unlike writing. Listeners can't reread. Repeat the takeaway at the turn and at the end.
- **Cues** go inline in the script itself (not in separate notes), each on its own line in brackets: `[PAUSE]` before reveals and after the hook, `[SLIDE: description]`, `[BEAT]` for a shorter pause, `[ASK AUDIENCE]` for a prediction question.
- **Format:** one paragraph per breath group, with a blank line between, so the speaker can find their place.

## Slides

- The story lives in the speaker's voice; slides support it. One idea per slide.
- Prefer a single image, a number, or a short phrase over bullets.
- Put the script in speaker notes, keyed to slides.
- If the user needs an actual deck file, hand off to a slides or pptx skill with the script and slide list.

## Format notes

Structure is chosen in `references/structures.md`; these are format conventions only.

| Format | Notes |
|---|---|
| Blog post or essay | Headline promises the question, not the answer. Subheads at structure beats for skimmers. |
| Case study | Include the before and after numbers in a callout. Get the customer's approval on quotes. |
| Incident or project story | Keep it blameless. Put the timeline in an appendix so the narrative can compress time. Link the formal postmortem. |
| All-hands or team update (spoken) | Keep it under 3 minutes unless the slot is given. End with what changes for the listener. |
| Memoir or personal essay | First person; present tense for the key scene can add immediacy. The reflection must be earned by the scene. |
| Fiction or lore | Establish the world's rules early and keep them; the audience learns the world as the character does. |
